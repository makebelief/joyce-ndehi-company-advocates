# Joyce Ndehi & Company Advocates

Production-ready static website adapted directly from the supplied reference template and branded for Joyce Ndehi & Company Advocates.

## Commands

- `npm run check` validates local links and titles.
- `npm run build` produces `dist/` for Vercel.
- `npm run dev` serves a local preview on port 4173.


UI refresh: adapted to the Njoki Mureithi red / black / white visual system while preserving Joyce Ndehi content and assets.
